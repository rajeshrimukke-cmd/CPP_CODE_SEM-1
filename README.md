# C++ Programming Lab-Units I to III
This repository contains the C++ programs from the C++ Programming Laboratory Manual upto Unit III. 
## Units

### Unit I - Introduction to Object Oriented Programming
1.Student Class with Details and Result Calculation
2. Rectangle Class with Member Functions
3. Product Class with Array of Objects

### Unit II - Classes and Constructors
1. Employee Class with Constructors
2. Book Class with Copy Constructor
3. Static Members and Friend Functions

### Unit III - Inheritance
1. Single and Multilevel Inheritance
2. Multiple and Hierarchical Inheritance
3. Hybrid Inheritance and Ambiguity Resolution

## Folder Structure

- `Unit_1/`
- `Unit_2/`
- `Unit_3/`

Each `.cpp` file is a separate lab program.
